# Demo — ace-step-ui

## Guion de demo (10 minutos)
1. **Apertura (1 min):** Presentar ACE-Step UI como alternativa local a Suno/Udio
2. **Instalación (2 min):** Clonar repo, instalar dependencias, ejecutar en local
3. **Generación (3 min):** Escribir letra, seleccionar estilo, generar canción con voz
4. **Descarga (1 min):** Descargar el archivo de audio generado
5. **Despliegue opcional (2 min):** Mostrar alojamiento gestionado o entrenamiento LoRA

## Recursos necesarios
- Equipo con GPU compatible
- Repositorio clonado localmente
- Navegador web moderno
- (Opcional) Cuenta de alojamiento gestionado para la parte de despliegue

## Métricas de éxito de la demo
- Canción generada en menos de 5 minutos
- Audio descargable y reproducible
- Usuario entiende que es local y sin suscripción
