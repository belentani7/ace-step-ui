# Métricas — ace-step-ui

## KPIs de adopción
| Métrica | Definición | Objetivo inicial |
|---------|------------|------------------|
| Descargas del repositorio | Clones y descargas ZIP desde GitHub | 100/mes |
| Instalaciones locales | Ejecuciones exitosas de `npm run dev` | 50/mes |
| Clientes de alojamiento gestionado | Contratos activos de 49 €/mes | 5 |
| Entrenamientos LoRA entregados | Modelos personalizados entregados | 2/mes |
| Horas de consultoría | Horas facturadas de integración | 10/mes |

## Métricas de producto
- Tiempo de generación de una canción (< 5 minutos objetivo)
- Tamaño del paquete de instalación (< 200 MB objetivo)
- Disponibilidad de la instancia gestionada (> 99% objetivo)

## Revisión
Las métricas se revisan mensualmente y se ajustan según adopción real.
